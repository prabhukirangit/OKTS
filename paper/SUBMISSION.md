# Submitting the OKTS preprint to arXiv

This directory is a self-contained, compile-ready preprint. This file covers
feasibility, the endorsement situation, what to attach, the exact arXiv
procedure, and no-endorsement fallbacks.

> **Status:** all numbers in `main.tex` are generated by `make_results.py` from a
> real run of the `okts.eval` harness. The paper is written to be **honest** —
> including an ablation showing that the category hierarchy and graph expansion
> are accuracy-neutral on this corpus, and a Limitations section. Do not "fix"
> those to look better; they are the paper's credibility.

## 2. Feasibility

**Content:** Feasible. arXiv moderators reject content that reads as product
documentation; this paper is framed as an empirical systems/IR study (problem →
related work → method → evaluation → ablation → limitations) with a reproducible
harness. That clears the content bar.

**The real gate — endorsement.** arXiv requires new submitters in most `cs.*`
categories to be **endorsed** (a vouch from someone with several papers in that
category). A first-time author with no institutional email will likely be
prompted for one. You have two paths:

- **Get endorsed:** when arXiv prompts, it names the category and gives you an
  endorsement code/link to send to a qualifying colleague. Any researcher with
  ≥3 papers in `cs.IR` (or the chosen category) in the last ~5 years can endorse.
- **Skip endorsement via a fallback venue** (§7), then cross-list to arXiv later.

## 3. Minimum requirements

- An arXiv account (free). Associating an **ORCID** is recommended.
- The paper as **LaTeX source** (preferred — arXiv compiles it): `main.tex`,
  `main.bbl`, `refs.bib`, and the `results/` fragments. PDF-only upload is
  allowed but discouraged and disables several features.
- A **plain-text abstract** for the metadata form (copy from the `abstract`
  environment; strip LaTeX).
- A **primary category** and optional cross-lists (see §6).
- A **license** selection (see §4).
- Everything self-contained; total size is tiny (well under the 50 MB limit).

## 4. License

Recommended: **CC BY 4.0** — it matches the Apache-2.0 code (open, permissive,
requires attribution) and maximizes reach. arXiv also offers its default
non-exclusive license if you prefer to reserve more rights. Pick this on the
first submission screen.

## 7. Compiling

**Local (MiKTeX is installed on this machine):**

```bash
python paper/make_results.py     # regenerate every number from the eval harness
cd paper
latexmk -pdf -pdflatex="pdflatex --enable-installer -interaction=nonstopmode -halt-on-error %O %S" main.tex
```

`--enable-installer` lets MiKTeX pull missing packages on first run; drop it once
the toolchain is warm, or just use `make results && make pdf`.

Alternatives that need nothing installed:

- **Overleaf:** New Project → Upload Project → drag `main.tex`, `refs.bib`, and
  the `results/` folder (keep the structure). Compiler pdfLaTeX, Recompile.
- **arXiv compiles for you:** upload the source and let arXiv's build produce the
  PDF (§8). Fix anything its log flags.

## 8. arXiv submission procedure (step by step)

1. Create/sign in to your arXiv account; link ORCID.
2. **Start Submission** → choose the **license** (CC BY 4.0, §4).
3. **Add files:** upload `main.tex`, **`main.bbl`**, `refs.bib`, and the
   `results/` fragments (as individual files preserving the `results/` path, or
   as a single `.zip`).

   > ⚠️ **arXiv does not run BibTeX.** You must include the generated `main.bbl`
   > or every citation renders as `[?]`. It is committed to the repo for exactly
   > this reason. Regenerate it with `make pdf` if you edit `refs.bib`.
   > Shipping `refs.bib` too is harmless and helps anyone rebuilding from source.
4. **Fix build errors** if any appear in the AutoTeX log, re-upload, rebuild.
5. **Metadata:** title, authors, the plain-text abstract, **comments** (e.g.
   "10 pages, 2 figures, 3 tables; code: github.com/prabhukirangit/OKTS"),
   **primary category `cs.IR`**, cross-lists `cs.AI cs.CL cs.SE`. Optional ACM
   class: `H.3.3` (Information Search and Retrieval).
6. **Preview** the generated PDF — check tables/figures render and no `??`
   appear for refs/cites.
7. If prompted for **endorsement**, follow §2. Otherwise **Submit**.
8. Submissions go on a short moderation hold and are announced on the next
   business-day cycle. You'll get the arXiv id by email.

## 9. No-endorsement fallbacks (post now, cross-list later)

If endorsement stalls, these accept independent authors with **no** endorser and
give you a citable record immediately:

- **Zenodo** — instant DOI, archival, pairs naturally with the GitHub repo
  (recommended first fallback; you can later add the arXiv id).
- **TechRxiv** (IEEE) — preprint server, no endorsement.
- **HuggingFace Papers** — good reach in the LLM-agent community.
- **SSRN** — general preprint host.

A common path: post to **Zenodo** for the DOI today, pursue an arXiv endorser in
parallel, then submit to arXiv and note the DOI in the comments.
